Predictive Nav

Navigate before you press Enter.

A Chrome extension that replaces the New Tab page with a bar that acts on what you are typing. Type blo and it goes to blocket.se — no Enter.

Try it Watch it without leaving Source on GitHub

Try it navigates for real — type am and you land on Amazon. Watch it adds ?demo=1, which replaces every navigation with a banner so you can see the decision without being taken away. The arrival overlay only exists in the installed extension: a web page cannot draw on another site.

What it does

Every keystroke resolves to exactly one intent:

You type Intent What happens
blo site 160-site catalog matches blocket → goes to blocket.se
hemnet.se address recognised as a URL → goes there directly
teknik search no site matches → jumps to the first organic result, past the ads
sv ambiguous four sites match → shows a list, navigates nowhere

Being wrong has to be cheap

Auto-navigation is only worth it if a bad guess costs nothing. So it only fires when the top candidate holds at least 75% of the matched score and beats the runner-up by 1.5×; Esc pauses it; and on arrival the destination shows a five-second overlay with the runners-up and a search row, so switching is one click rather than a back-button round trip.

Inside the sites

On catalog sites it also reads the site's own autocomplete and activates the top row: type mac on Foodora and it opens McDonald's; on Elgiganten it opens the MacBook results. It never guesses what "mac" means — the site already knows, and its suggestion list is standard role="listbox" markup, shadow DOM included.

It never runs on banks, government services, health, payment or checkout pages. Eighteen sensitive hosts are excluded from the content script at build time.

Install it

  1. Clone or download the repository.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the extension/ folder — or just drag the folder onto the page.
  4. Open a new tab and type blo.

The in-site overlay and search auto-pick need the installed extension — a web page cannot draw on another site. The demo above covers the New Tab bar only.

Run it locally

node tools/serve.mjs
node --test test/*.test.mjs

Honest numbers

Chrome already prerenders its address-bar predictions, so what this removes is roughly 200–400 ms per navigation. At about 3 seconds to recover from a wrong guess, it has to be right well above 90% of the time to break even — which is exactly why the confidence thresholds, the Esc key and the second-chance overlay exist. As a mass-market product the gap this fills exists on purpose. As a personal tool over your own twenty sites, the accuracy is high enough that it pays for itself.

No frameworks, no build step, no tracking. Favicons load from each site's own origin. 60 unit tests.
